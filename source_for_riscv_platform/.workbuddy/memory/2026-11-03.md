## RISC-V 裸机 newlib-nano printf 支持

工程：source_for_riscv_platform（rv32i 裸机，RAM @0x0 64K，UART0 @0x80000000）

- 工具链：/Users/orange/opt/xpack-riscv-none-elf-gcc-15.2.0-1（riscv-none-elf-gcc 15.2.0，multilib 有 rv32i/ilp32）
- 改造内容：
  - 新增 `syscalls.c`：`_write`（UART 输出，\n 自动转 \r\n）、`_sbrk`（用 `__heap_start`/`__heap_end`）、`_read`、`_close`、`_fstat`、`_isatty`、`_lseek`、`_exit`、`_kill`、`_getpid`、`_getentropy`
  - `startup.S`：设 sp → 清 bss → `call __libc_init_array` → `call main` → `call exit`（用 exit 而非 _exit，保证 flush）
  - `linker.ld`：加 `__data_start/__data_end`、`__bss_start/__bss_end`、`__heap_start/__heap_end`、`__preinit_array_*`/`__init_array_*`（PROVIDE_HIDDEN），`.bss` 移到镜像末尾，STACK_SIZE=4K，加 `/DISCARD/`
  - `makefile`：`--specs=nano.specs --specs=nosys.specs -nostartfiles`（不要用 -nostdlib，否则要手动 -lc），`-mcmodel=medany`（UART 在 0x80000000 需要），`-Wl,--no-warn-rwx-segments`
- 体积：约 9.1KB text（不含 %f）；打开 `-Wl,-u,_printf_float` 后约 36KB（+26KB 软浮点）
- 验证：在 /tmp 做 RAM@0x80000000 + UART@0x10000000 的 qemu-virt 变体，`qemu-system-riscv32 -M virt -bios none -nographic -kernel`，printf / %s / %d / malloc(_sbrk) / %f 全部实测通过
- 注意：main 里 `setvbuf(stdout, NULL, _IONBF, 0)` 可省 1KB heap 并即时输出
