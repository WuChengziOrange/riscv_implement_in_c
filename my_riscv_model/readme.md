# Q&A 模拟流水线实现 riscv

## 1.如何仿真流水线？

* 五级流水线分别是：IF ID EX MEM WB
* 这五级流水线每一个单元都只执行组合逻辑
* 在 top 文件里面实现控制单元的逻辑
* 每次组合逻辑执行结束之后，再在控制单元准备下一次组合逻辑的输入

## 2.如何处理分支跳转？

1. 在 EX 阶段结束后才得出是否要跳转，以及跳转地址是多少的结论
2. 因此在 EX 阶段前面的 IF ID需要把 valid 变成 0，它们相当于被刷掉了
